# AQB-012 · ¿Zapatillas en el lavarropas?

- **Pilar:** Zapatillas · **Servicio:** Lavado de zapatillas
- **Guía web (mejorada, misma URL):** https://www.aquabonlavanderia.com/blog/se-pueden-lavar-zapatillas-en-el-lavarropas
- **Formato:** Reel
- **Mensaje clave:** el centrifugado y el calor despegan suelas, deforman la horma y castigan el tambor del lavarropas.
- **No decir:** "nunca se pueden lavar", "garantizado". Nada de precios ni plazos.

**Hook (0-3 s):** "Lo que le pasa a tu zapatilla dentro del lavarropas."

## Carrusel de apoyo (6 slides, opcional)

1. **Gancho:** ¿Zapatillas en el lavarropas? Esto es lo que nadie te cuenta.
2. **El golpe:** el lavarropas está pensado para telas que se doblan. La zapatilla no se dobla: golpea.
3. **La suela:** el centrifugado tensiona el pegamento. Una unión cansada se abre.
4. **La horma:** talón y puntera mojados y golpeados se aplastan y no vuelven.
5. **Tu lavarropas:** una zapatilla mojada pesa, desbalancea la carga y castiga el tambor.
